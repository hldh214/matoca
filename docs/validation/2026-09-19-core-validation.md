# 自動受付の実店舗検証記録

この開発では実際の受付申込・取消・来店検証を行っていません。
以下は、利用者が別途選んだ来店時に確認するための記録項目です。

1. 加盟店・店舗・来店日・時差を含む到着予定・人数・確認項目・早着許容・予測誤差を記録する。
2. シミュレーションで判断履歴を確認する。公式目安の有無／下限表示、確認時刻、予測、保留理由、最初の条件成立時刻を確認する。申込なしの結果は受付成功を示さない。
3. 実際の自動受付を利用する場合は、新しい実受付タスクとして内容と同意を確認する。シミュレーションを実受付に変換しない。
4. 当日の受付時刻・受付番号・申込時の公式目安を記録する。受付結果が不明な場合は再申込せず、現在の受付を確認する。
5. 実到着時刻・実呼び出し時刻・呼び出しを確認した方法を記録する。組数0の観測だけでは正確な呼び出し時刻を断定しない。
6. 実際の呼び出しが到着予定より何分早い／遅いかを比較する。公式目安の変化、履歴再現の時刻条件、実際の待ち時間は区別する。

履歴再現は指定した日本時間の日付の記録だけを順番に使います。
各時点より後に判明した実待ち時間は、その時点の予測には使用しません。
当時のフォームとアカウント状況は不明であり、欠測・エラー・古い情報から受付成功を推定しません。
