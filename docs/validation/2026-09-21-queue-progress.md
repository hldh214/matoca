# 組数による進行状況の比較

> **廃止済み・履歴資料**：以下は当時の仕様であり、現在の機能説明ではありません。
> 2026-09-22 のコンソール簡素化により、組数の減少速度による予測・等速比較の
> UI 表示は廃止されました。現在は公式の待ち組数・目安時間・受付状態を表示します。
> 現行仕様は [コンソール簡素化](2026-09-22-console-simplification.md) を参照してください。

順番待ち詳細から、前の組数と現在の公式目安時間を毎分保存します。
人数は受付フォームにのみ使用し、進行速度の計算には使用しません。
同じ分の一覧取得で値が省略されても、保存済みの詳細値は消去しません。

加盟店ページの現在の順番待ちに次を表示します。

- 最新の公式目安時間。
- 受付時の公式目安から経過時間を引いた、等速想定の残り時間。
- 初期組数が取得できた場合、等速想定に比べ何組先行・遅延しているか。
- 直近5・15・30分の組数減少速度と、その速度が続いた場合の残り時間。

窓全体の記録が不足する場合、欠損値や2分を超える取得間隔がある場合、
組数が減少していない場合は速度による残り時間を表示しません。
0組は正式な呼出確認ではないため、速度から0分と断定しません。
更新が古い場合と終了済みの受付では進行予測を非表示にします。
公式目安が「以上」の場合は、受付時目安による等速比較を行いません。

これは途中経過の比較であり、呼出精度の実測評価や実入店時刻ではありません。
途中の組数増加や受付取消等もあり、線形に進む保証はありません。
既存DBはスキーマ11へ追加変更のみで移行し、過去の公式目安は補完しません。
